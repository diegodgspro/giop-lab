## Release notes

The first public portfolio presentation of GIOP connects synthetic infrastructure
monitoring, ITSM/CMDB, persistent event correlation and operator-governed response.
It does not represent Guaratinguetá's live municipal production environment.

Highlights:

- Zabbix Problem/Recovery translated into GLPI Incident/follow-up with persistent correlation.
- Responsive read-only N3 Control Center with current API state and a runbook catalog.
- PowerShell health/diagnostics plus dry-run-first, explicitly approved fixed-target recovery.
- Optional AI analysis using sanitized context and strictly validated structured output.
- Real Ollama 0.35.1 / llama3.2:3b inference, alongside deterministic non-LLM fixtures.
- 71 regression cases and historical synthetic end-to-end/browser validation.
- Public-safe captures, architecture, staged setup and a 5–8 minute operator demo.

Historical example: Problem 41 → Ticket 97 → Recovery 42 → Follow-up 4 → Healthy.
AI never executes commands/runbooks. The real model produced valid structure but
partly ignored supplied workload state and recommended RB-OPS-001. Confidence is
not calibrated probability. Operator review and final decision remain authoritative.

This is a single-pilot local LAB, not production orchestration, autonomous AIOps,
an HA service or a completed authentication/TLS/egress design. No new runtime feature
was added for v1.0 preparation. Historical phase tags/evidence are retained.
